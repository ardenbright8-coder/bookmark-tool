# bookmark-tool · Agent 看板的手机端和设计记录

电脑上一块常驻的「Agent 看板」：随手记、给各家 AI（Claude / ChatGPT / Pi / Antigravity / Hermes）派活、AI 领活干完写报告等人审。手机上的收发箱 APP 跟电脑看板同步。

- `手机APP_收发箱_Flutter/` —— 手机端（Flutter，仅安卓）。安装包在 [Releases](../../releases)
- `通道（阿里云ntfy·部署与收信）/` —— 手机和电脑之间的中转站（自建 ntfy）部署说明
- `设计思路（看板·聊定的设定·一条三本账）/` —— 每条设定：现在怎样、为什么、改过什么
- 电脑端代码在另一个仓库：[multi-agent-desktop-pet](../../../multi-agent-desktop-pet)（看板寄住在桌宠程序里，`src/bookmark/`）
