## 三、和手册的偏差（逐条，为什么）

1. **部署根 `/opt/ntfy-deploy` → `/opt/bookmark-ntfy/`**（用户中途硬规矩：全部集中一个自解释夹，见文末删除三步）
2. **HTTPS 域名版 → IP 直连 HTTP 版**：用户域名/DNS 未就绪，按工单走最小可用版。改动：server.yml `base-url=http://116.62.217.189`、`behind-proxy: false`；compose 端口 `127.0.0.1:2586:2586 → 80:2586`；跳过 Caddy
3. **手册 `ntfy user add --config /etc/ntfy/server.yml` 不被 2.11 接受**（`flag provided but not defined: -config`）→ 容器默认就读 `/etc/ntfy/server.yml`，去掉即可
4. **手册 `--password` 旗标不存在** → 非交互设密码用环境变量：`docker compose exec -T -e NTFY_PASSWORD=xxx ntfy ntfy user add 用户名`
5. **手册权限简写 `w`/`rw` 不被 2.11 接受** → 用全称 `write-only` / `read-write`
6. **手册 curl 验证端口写 80 域名** → IP 版直接 `http://116.62.217.189/`（服务器本机验证打 `localhost:80`，不是 2586——宿主映射的是 80）
7. **🚨 手册要修**：以上 3/4/5 是手册原文错误，下次照手册敲会卡死，应更新手册原文
