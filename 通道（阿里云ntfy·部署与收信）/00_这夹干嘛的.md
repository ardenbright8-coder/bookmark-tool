# 通道（阿里云ntfy·部署与收信）

**这夹干嘛**：书签工具的消息通道层——把 ntfy 邮局架到阿里云 VPS（缓存长、带密码、国内直连快），电脑端守着它收手机发来的记录、发回执。

## 里面有啥

- `deploy\` —— 上云全套：docker-compose（ntfy+Caddy）、ntfy配置、照着敲的部署手册（含回滚）
- `receiver\` —— 电脑端收信+回执模块（纯Node无界面）：界面区用 `start()` / `sendReceipt()` 两个函数调它
- `deploy\服务器信息（本地·不进git）.md` —— 真实凭证落点（已进 .gitignore），用户给了凭证才填

## 想干什么去哪

- 部署/重装/升级/回滚邮局 → `deploy\部署手册（照着敲就上）.md`
- 改收信/回执逻辑 → `receiver\receiver.js`，先读它开头的标签块和 README
- 查链路（手机发了电脑没收）→ 先跑 `receiver` 单测，再按部署手册「验证」节逐条对

## 硬规矩

- 部署物里的域名/账号/密码全是占位符；真值只进服务器信息文件（在 .gitignore 里）
- receiver 的一切网络异常内部消化（指数退避重连），不许把异常抛给界面区
- 改缓存时长/账号/端口，必须同步改部署手册对应行
