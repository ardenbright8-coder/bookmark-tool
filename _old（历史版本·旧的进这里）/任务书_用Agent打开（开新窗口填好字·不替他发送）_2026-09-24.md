   - 写代码工作流：E:\个人AI资源管理\60_公用资源（钩子·skill·搜索引擎·可后期扩展）\30_Skill管理（给Codex和Claude用的能力包）\通用skill（谁都能用）\编程Skill集（写代码的skill）\写代码工作流（开局·保养·日常改）\SKILL.md

3. 只动这件活要动的文件。**别的窗口也在改这个看板**：改之前看一眼文件是不是刚被改过；提交时只提交你自己改的那几块（`git apply --cached` 挑块），别人没提交的改动原样留着。

6. 先把你的理解和方案讲给用户，他点头再动手。干完汇报：动了哪些文件、测试结果（红的原样贴）、没做的和为什么。

## 这次的事

### 要做成什么样

看板（桌宠程序里的「Agent 看板」，代码在 `E:\个人AI资源管理\10_按项目存放（某个项目专用的脚本和资料）\01_手作园（自己从0搓的·应用网页工具）\应用\多Agent桌面宠物（统一通知与权限说明）\app（Electron本体·带git）\src\bookmark\`）每一条（和每一捆的捆头）左边有六个点（⠿），在 agent 组里点开，最上面已经有两项（2026-09-24 做好了，见设定库设定15）：

- **启动 Agent · 带编程**
- **启动 Agent · 普通**

现在点了只做一半：看板给这个窗口起名（如 Claude-3），把一句短话放进剪贴板，提示用户「开一个新的 Claude 窗口，Ctrl+V 再回车」。那句短话长这样：

`领看板的活：node "E:/…/scripts/bookmark-cli.mjs" next <捆号或条目id> --by Claude-3 --coding`

AI 敲了它，就会自己去看板领活、拿到全文和干活规矩（`next` / `done` / `release`，见仓库根 `AGENT_INTEGRATION.md`「看板领活」节）。**你不用管活的内容，只管把这句短话送进一个新窗口。**

你要补的另一半：
1. 看这一条在哪个组，就开那个 AI 的**一个全新窗口**：Claude 组 → Claude Code；ChatGPT 组 → Codex；Pi Agent 组 → Pi；Hermes 组 → Hermes。用户自己加的组认不出是谁：照旧只复制，不开窗。
2. 等那个 AI 程序准备好，把**那句短话**填进它的输入框（短话由主进程 IPC `bookmark:launch-line` 生成，别自己另拼）。
3. **停住，不按回车。** 用户看一眼、自己按回车发出去。

### 已经查过的（别重查）

- `claude "文字"`、`codex "文字"` 这种带着话开的写法，一开就**直接发出去了**，没有「只填不发」的开关。所以不能用它。
- 可行的路：开新终端窗口跑 `claude` / `codex` / `pi` / `hermes` → 等它准备好 → 确认这个新窗口在最前面 → 把文字放进剪贴板、模拟一次 Ctrl+V 贴进去。**新窗口不在最前面（用户中途点了别处）就不贴**，改成右下角提示「窗口开好了，按 Ctrl+V 再回车」。
- ChatGPT 组用户说的是「桌面端」，对上的是 Codex。Codex 用命令行还是桌面程序、哪个能这样填字，你先查清楚，写进方案里给用户挑。
- 看板主进程已经用 koffi 调过 user32（`panel-window.ts` 的 `SetWindowPos`、`SendMessageW`），要调 Windows 接口照那个写法（HWND 用 `uintptr_t` + BigInt）。

### 死规矩（碰了就不许交）

1. 🚨 **绝不按回车、绝不替用户发送。** 用户原话：「全自动很容易被 Anthropic 识别成我搞自动化那个东西，那就很危险了」。只准「开窗 + 贴字」，而且只在用户点了菜单那一下之后。
2. 🚨 只往**这次新开的那个窗口**里贴。认不准是哪个窗口，就退回剪贴板提示，不许往别的窗口里打字。
3. 🚨 不碰 Windows 设置、注册表、系统服务；不装新东西（要装先停下问用户）。
4. 看板隔离铁律：这块出任何错（程序没装、开不了窗、超时）都只在看板里提示一句，不许让桌宠本体跟着崩。
5. 渲染层函数一律 `bm` 前缀；新 IPC 走 `preload.ts` 的 `window.bookmark`；别开 nodeIntegration。

### 怎么算干完

- 四个组各点一次「启动 Agent · 普通」：各开出一个新窗口，那句「领看板的活：…」在输入框里，没有被发出去。用户亲眼验；他按回车后 AI 能领到活、看板出「🔄 窗口名 在干」。
- 「启动 Agent · 带编程」：那句短话末尾带 `--coding`。
- 开窗途中点别的窗口：不会贴错地方，看板提示「按 Ctrl+V 再回车」。
- 自动测试：真 AI 程序在测试里开不了，用一个假的「AI 程序」（比如一个记下收到了什么的小脚本）代替，验「开了窗、贴进去的字对、没有回车」。
- 看板验收关卡全跑，跟基线比没有新红（已知基线见 `src\bookmark\AGENTS.md` 验收节；另外 2026-09-24 起 `verify-bookmark-handoff.mjs` ⑥ 会超时，是单击改字那次改动带出来的，不算你的）。
- 设定库设定15「还没做的」那条改成已做，`src\bookmark\AGENTS.md` 门牌同步。
