# 设定 16 · 条目贴图（Ctrl+V 贴进光标处·缩略图·交给 AI 换成路径） —— 设计规则

2026-09-24 立。主体由另一个窗口写，本窗口补完验证后提交；用户当面的原话没留下，理由那份暂缺，等用户补。

## 该长什么样

- 在输入行或改字框里 Ctrl+V 贴截图，或点框里右上角的小图片图标选文件：图贴在**光标所在位置**，可以一次贴多张
- 🚨 贴图按钮只是框里右上角一个淡淡的小图标（跟条目的复制图标对成一列），**不许单独占一行、不写字**（2026-09-24 用户：「图片单独占一行……做个图标就行了，别那么重」）
- 有图时输入框换成图文框：图显示成**跟一行字差不多高的小图**，像图标嵌在字里，不把排版撑乱（用户：大了看着乱）；鼠标移到小图上，右上角露出一个小 × 移除这张
- 板上条目里也显示小图；点小图弹大图，不会进改字；大图右上角一个 × 关掉，按 Esc、点外面也能关
- 复制、交给 AI（行尾复制、启动 Agent 领活）时，图的位置换成「图片文件：完整路径」，并提示 AI 用读图工具打开，前后文字顺序不变
- 不接收外来 HTML、不接收拖进来的路径；非图片、超过 20MB、尺寸过大的拒收
- **图片标注（第三版，2026-09-24 用户：学 ChatGPT 那样打开就能标）**：点小图弹大图，**打开就能标**，没有「标注图片」按钮
  - 图下面一排小工具：● 编号（点一下落一个带号的圆）、框（圈和方块合成一个）、↗ 箭头，最右 ↶ 撤销；没有文字工具
  - 🚨 **全图一套流水号** 1、2、3，不分箭头号、框号；删了一个后面的往前补
  - 每画一个，下面自动多一行「③ 这里要怎么改…」，光标直接跳过去；说明**只写在图外**，不写在图上
  - 🚨 **没有保存按钮**：画一笔、写一个字就自动存（右边淡淡闪一下「已自动保存」），关掉大图就是完成
  - 按住编号能拖走整个标注；点编号跳到它那行说明；× 或选中按 Delete 删掉；Ctrl+Z 撤销最后一个；框和箭头没拖开只点了一下＝落一个编号
- 标注**不烧进原图**：单独存 `<图>.marks.json`（位置按图片宽高比例存），另存一张带编号的 `<图>.marked.png` 只给 AI 看；正文里的图片标记不换。删光了两个附属文件一起清掉
- 交给 AI 时，标过的图给「图片文件（标了编号的）」＋「原图」＋编号清单，一行一个：「① 点，在（从左 12%、从上 30%）：这个按钮改成绿色」「③ 箭头，从（…）指到（…）：…」，AI 不用自己认红线

## 代码落在哪

| 干什么 | 在哪 |
|---|---|
| 存图、读图（磁盘边界） | `image-ipc.ts`：只收图片字节，解码后存 PNG 到 `attachments`；读图只认本夹文件名 |
| 图片标记、交给 AI 时换成路径、改字后附件对账 | `inline-images.ts` → `inlineImageNames` / `imagesForAgent` / `reconcileImages` |
| 图文编辑框、缩略图、大图 | `renderer\inline-images.js/.css` → `bmBindImageEditor` / `bmRenderImages` / `bmShowImage` |
| 图片标注 | 界面 `renderer\inline-images.js/.css` → `bmShowImage` / `bmBindMarks` / `bmDrawMarks`；存取 `image-ipc.ts` → `bookmark:image:marks:get/set`；清洗和给 AI 的清单 `inline-images.ts` → `sanitizeMarks` / `describeMarks` / `imagesForAgent` |

### 硬约束

1. 🚨 存档里图只存标记 `[图片:image-….png]`，界面上一律画成缩略图，不许把标记露给用户看。
2. 🚨 贴图途中（`bmImagesBusy`）压住重画，不然正在贴的框会被冲掉。
3. 🚨 大图整块 `-webkit-app-region: no-drag`：大图弹在窗口顶部，关闭钮会落进标题栏「按住拖窗口」的区域，真鼠标点了是拖窗口、按钮收不到（Playwright 点击绕过这层，测不出来，只能验样式）。
4. 🚨 测试样图必须是校验和都对的真 PNG，而且要够大（200×120），太小本来就比一行字矮，验不出小图有没有缩：Electron 解码器很严，坏校验和直接判「无法读取」（2026-09-24 就卡在这）。
5. 🚨 从改字框打开大图时压住失焦提交（`bmImagesBusy`），不然改字框会先被销毁。
6. 🚨 带编号那张图的线粗和编号大小按「屏幕上看到的」折算（记下显示宽度再算），关窗后 img 已拿掉量不到尺寸，别在存的那一刻现量。
