# 设定 18 · 两档：日常档 / 睡觉档 —— 设计规则

2026-09-24 立。

## 该长什么样

- 标题栏右边一个档位钮：**☀️ 日常档**（淡绿）/ **🌙 睡觉档**（夜蓝底），点一下切换；存 `<数据夹>\bookmark\mode.json`，重开还是那一档。缺档、坏档一律日常档
- **日常档**＝原来那套（设定15）：AI 干完先讲给用户验，用户说可以才 `done`
- **睡觉档**：用户睡了，AI 一条接一条往下干
  - 干完**不等用户、不删**，写一段大白话报告：`report <条目id> --by 窗口名 --text "做了啥、改了哪些、怎么验的、还有啥没弄完或要他拍板的"`
  - 条目标成「✅ 干完待审 · 窗口名 · 时间」，报告挂在条目下面（淡绿左边线），带一个「可以，删掉」按钮——用户早上看完点它才删
  - 写完接着 `next --to "组名" --by 窗口名` 领这组下一条，一直干到没有可领的
  - 额度快用完、上下文快满：先 `handoff` 写交接单（干到哪、下一步、新窗口要带哪些文件）派回这组，再 `release` 手上这条，然后停
  - 要用户拍板、有风险的事（删东西、动系统、花钱、发出去）不干，写进报告等早上定
- **睡觉档看板每半小时看一眼**（切到睡觉档那一下也马上看一眼）：哪组「还有活、又没人在干」，就开这组的窗口、贴好「按组领活」那句（`领看板的活：node "…/bookmark-cli.mjs" next --to "Claude" --by Claude-5`），提示「开好窗、贴好领活那句了（没按回车）」
  - 🚨 **只贴不回车**（设定15铁律）：发不发永远是用户按
  - 同一回卡住只开一次：开过窗还没人来领，下回不再开；有人来领了记账清掉，下回卡住还能再开
  - 几组要开就一组一组来，等上一组贴完再开下一组（同时开会抢最前面）
- 报告过的条目**谁也领不走**（按捆领、按条领、按组领都跳过）

## 代码落在哪

| 干什么 | 在哪 |
|---|---|
| 档位存档怎么读、到点该给哪几组开窗 | `sleep-mode.ts` → `parseBoardMode` / `planNudges`（纯函数） |
| 报告字段、写报告、按组领、报告过的不领 | `store.ts` → `report` / `reportedBy` / `reportedAt`、`report()`、`claimInGroup()`、`claimFrom()`（按捆、按组共用） |
| 命令 `next --to`、`report`，领活说明分两档 | `cli-server.ts` → `parseClaimArgs` / `handleClaimRequest`（`/report`、`/next` 带 `group`、回包带 `mode`）/ `formatClaimMessage`；`scripts\bookmark-cli.mjs` |
| 档位读写、半小时看一眼、开窗贴好 | `panel-window.ts` → `readBoardMode`、IPC `bookmark:mode:get/set`、`runSleepCheck`、`startSleepTimer`；开了哪几组发 `bookmark:sleep-nudged` |
| 档位钮、干完待审块 | `renderer\index.html` `#mode-btn`；`renderer\bookmark.js` 初始化那段、`bmBuildTask` 里的 `.task-report`；`styles.css` 末尾「两档」一段 |

### 硬约束

1. 🚨 **领活说明还是只在 `formatClaimMessage` 写一次**，两档分两段，所有 AI 同一份。睡觉档那段不许出现 `done`。
2. 🚨 **睡觉档开窗只贴不回车**，跟设定15同一条铁律；要改成自动发出去，先问用户（风控）。
3. 默认、坏档都回落日常档——日常档是安全的那一档。

## 拿什么验收

```
npm run build && node --test dist/testkit/tests/bookmark-sleep.test.js
node scripts/verify-bookmark-sleep.mjs
```

单测 9 项：report 写报告不删、别人的不收、空报告不收；按组领从上往下、报告过的跳过；按捆领也跳过；旧库补 null；档位只认 sleep；该开窗的组、开过不再开；命令参数；`/report`、`/next` 带组和档位；两档领活说明。界面验证 ①～⑧：档位钮默认日常档、点一下切睡觉档并存档、重开还在；切过去马上给有活没人干的组开窗（测试实例不真开）；真敲 `next --to` 领到的是睡觉档说明；真敲 `report` 后看板出「✅ 干完待审」和报告、在干没了；再领领到下一条；点「可以，删掉」删掉；切回日常档说明回到 `done --ok`。2026-09-24 连跑三轮全绿。
