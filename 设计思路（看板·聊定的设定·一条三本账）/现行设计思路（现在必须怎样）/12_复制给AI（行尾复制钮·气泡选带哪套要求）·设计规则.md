# 设定 12 · 复制给AI（行尾复制钮·六个点菜单） —— 设计规则

2026-09-24 立，当天改成第二版（改了什么见历史理由同编号那份）。文件名保留「气泡选带哪套要求」是第一版的叫法，没改名，免得断链。

## 一条铁律

🚨 **两个入口各管一件事，别混：行尾复制＝给用户自己用；左边六个点＝交给 AI 干活。**

## 该长什么样

**① 行尾复制（给用户自己用，拿去别处商量）**
- 常显，平时淡（不透明度 0.35），鼠标移到这一行变清楚；不许全藏（用户：藏久了看不见）
- 点一下直接把这条的文字（带链接、详情）放进剪贴板，右下角提示「已复制这条」；不弹气泡、不带要求

**② 左边六个点（⠿）＝交给 AI 干活**
- 只在 agent 组里出现「启动 Agent · 带编程」「启动 Agent · 普通」两项（名字就这两个，简洁明了）；待定页不出现（待定是还在商量）
- 点了干什么、领活怎么领，全在设定15
- 下面一条细线隔开，照旧是「收回待定 / 收回交接单专区」「删除这条」；这条正被 AI 领着时多一项「放回去」

**③ 右键菜单精简**
- 分组页、交接单专区：不列「派给 →」（拖到组头就是派给谁）
- 待定页：照旧有「派给 →」各组
- 「收回」保留

**④ 组头按钮变小**：＋ 是细线图标（svg），不带圈、不带边框，鼠标移上去才垫一层浅底（收起钮已撤、＋ 挪到组名旁，见设定13）

**⑤ 要求模板在哪改**：⚙ 设置里「要求模板 · 打开文件夹」。「启动 Agent · 带编程」用的是里面的 `带编程.md`。

## 代码落在哪

| 干什么 | 在哪 |
|---|---|
| 拼复制文字（纯函数） | `src\bookmark\templates.ts` → `composeForAgent` |
| 写剪贴板、打开模板夹 | `panel-window.ts` → IPC `bookmark:copy-for-agent` / `bookmark:templates:open` |
| 行尾复制 | `renderer\bookmark.js` → `bmBuildTask` 行尾 `.t-copy` |
| 六个点菜单 | 同上 → `bmShowCtxMenu`、`bmLaunchOptions`、`bmReleaseItem` |
| 设置里的模板入口 | 同上 → `bmAddTemplatesSettingRow` |
| 细线图标 | 同上 → `BM_ICONS` / `bmIcon` |

模板夹：`<appDataRoot>\bookmark\要求模板\`（真机＝`%APPDATA%\AgentPetHub\bookmark\要求模板\`）。

### 硬约束

1. 🚨 **剪贴板在主进程写（electron `clipboard`）**，别用渲染层 `navigator.clipboard`——看板常驻沉底、经常没焦点，渲染层写剪贴板会被拒。
2. 🚨 **复制的文字在主进程按 id 现取条目现拼**，别拿渲染层手里的旧对象拼——自动存档 400ms 防抖，手里那份可能是旧字。
3. 复制钮是 `button`，拖动起手（`bmBindDrag`）已经跳过按钮，别给它加拖动。
