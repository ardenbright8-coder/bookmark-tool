# 设定 17 · 第一格常驻空白框（点进去就写·回车落到第二格·不用按加号） —— 设计规则

2026-09-24 立。

## 该长什么样

- 待定区和每个 agent 组，**第一格永远是一个空白框**（淡淡的虚线框，提示字「写一条…」），点进去直接写，不用先按加号
- 组名旁边**不放小加号**；交接单专区例外，照旧点小加号冒输入行（设定13）
- 写的时候边写边存（设定06「写了就是写了」不变）：第一个字起就在看板上第二格现身，框里继续写
- **回车 = 这条落到第二格，框清空，光标留在框里接着写下一条**；点别处 / Esc = 同样落下去、框清空，光标离开
- 没写字就点别处：什么都不多，空白框还在
- 右键组标题 = 光标进这组的空白框；条目右键「在上面 / 下面插一条」照旧冒一行插进去

## 代码落在哪

| 干什么 | 在哪 |
|---|---|
| 每组第一格画空白框 | `renderer\bookmark.js` → `bmFillTaskList`（交接单专区不画，它走老的「有草稿才冒输入行」） |
| 空白框 / 右键插入行 | `bmBuildInsertRow(groupKey, blank)`：空白框第一个字起开草稿（`anchorId: null`），只认写在最上面的草稿 |
| 按组找输入框 | `bmFindInsertInput(groupKey, blank)`；`bmRefresh` 重画后按「哪个组、是不是空白框」把光标放回去 |
| 样式 | `styles.css` → `.blank-row`、`.insert-row.blank-row textarea` |

### 硬约束

1. 🚨 **空白框不带 `task` 类**：它不是条目。带了会被拖动当成落点、被「第一条」「数条目」算进去（2026-09-24 实测：拖到最前全错、行尾复制找不到）。
2. 🚨 **找输入框必须按组找**（`bmFindInsertInput`），别再用 `document.querySelector(".insert-row textarea")`——每组都有空白框，第一个永远是别的组的。
3. 🚨 收尾清草稿只清自己那份（`bmInsertCommit` 里 `if (bmInsertDraft === draft)`）：存档那会儿用户可能已经在别的框开了新草稿。
4. 只有空白框自己的草稿才让它回车 / 失焦去存档（`mine()`），别的框的草稿它不碰。

## 拿什么验收

```
npm run build && node scripts/verify-bookmark-insert.mjs
```

①～⑦：第一格是空白框、没有加号；点进去光标在框里；不写字点别处不多条目；写了点别处 / 回车都落到第二格、框清空，回车后接着写第二条也行；打字中途重画不丢字；分组页每组都有、写进哪组落哪组；交接单专区保留加号。拖动、复制、贴图、页签几关也改成点空白框。2026-09-24 全绿。
