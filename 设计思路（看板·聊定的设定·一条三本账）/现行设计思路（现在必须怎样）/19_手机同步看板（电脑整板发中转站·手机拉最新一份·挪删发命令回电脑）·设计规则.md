# 设定 19 · 手机同步看板 —— 设计规则

2026-09-24 立。

## 该长什么样

**同步怎么走**（中转站＝阿里云上的 ntfy，缓存 7 天）
- 电脑 → 手机：看板每 5 秒看一眼整板变没变，变了就把整板抄一份发到 `bookmark-board` 主题（电脑只写、手机只读）；电脑开着时每 6 小时补发一份
- 手机 → 电脑：记一条照旧走 `bookmark-up`；挪组 / 删条（含「✅ 干完待审」下面的「可以，删掉」）发 `type=op` 的命令（`op=assign|delete`、目标条目 `id`、`assignee`），电脑收信时照做、回执照发
- 手机打开、下拉、每 30 秒拉一份最新整板；中转站 ntfy 2.11 不支持「只要最新一条」，按 1 小时 → 1 天 → 7 天放宽找；断网给上一份存下来的
- 电脑关着：手机看的是最后一份；手机记的、发的命令都存在中转站，电脑开了补收
- 中转站单条消息上限已从 4K 调到 256K（`server.yml` 的 `message-size-limit`），整板一份发

**手机看板长相**（照电脑看板）
- 草木皮肤；标题栏写「电脑 几点 的看板」和电脑现在是 ☀️ 日常档 / 🌙 睡觉档（只看，切档去电脑）
- **单页**：💭 待定置顶、下面按电脑的分组顺序排、最底下交接单专区（2026-09-10 用户拍板「待定置顶 + 按 agent 分组的单页形态不许改」，所以不照电脑分两个页签）；**不放数数的小标**、组框不折叠（设定13）；分组名单以电脑为准，手机不加组
- 每组第一格是常驻空白框（设定17）：点进去写，回车就发、框清空、光标留着；右边小图标＝带图记一条（图只存手机）
- 条目 01 02 编号，最多三行，点开看全文；图片标记显示成 🖼；带「📋 交接单」「🔄 谁在干」「🖼 几张图」小签
- 「✅ 干完待审 · 谁 · 几点」块 + 报告 + 「可以，删掉」（设定18）
- 长按条目 → 挪到哪组 / 删掉这条；发出去先照着改好，下一份整板到了以电脑为准
- 手机自己发的、看板上还没有的，单列在组最上面，标「⏳ 已送出，等电脑收」/「📨 电脑已收，等下一份看板」

## 代码落在哪

| 干什么 | 在哪 |
|---|---|
| 抄整板、认手机命令、照做、定时发 | 电脑 `src\bookmark\board-sync.ts` → `buildBoardSnapshot` / `parsePhoneOp` / `applyPhoneOp` / `startBoardPublisher`；`panel-window.ts` 收信那段启动发整板 |
| 收命令 | 电脑 `inbox.ts` → `handleMessage` 先认 `type=op`；配置 `boardTopic` 缺省 `bookmark-board` |
| 拉整板、断网备份、哪些是自己发了还没进看板的 | 手机 `lib\core\board_sync.dart` → `BoardSync.fetch` / `seenKeys` / `notOnBoardYet` / `displayText` |
| 发命令 | 手机 `lib\core\sender.dart` → `sendOp`（不进本地账本） |
| 看板页 | 手机 `lib\ui\agent_board_page.dart`（上半是新看板，下半带图记一条 / 本地条目详情两个弹窗沿用） |
| 中转站主题和权限 | 服务器 `/opt/bookmark-ntfy/`：`server.yml` 加了 `message-size-limit: "256K"`；`ntfy access pc-receiver bookmark-board wo`、`ntfy access phone-sender bookmark-board ro` |

### 硬约束

1. 🚨 **命令只认 `assign` / `delete`**，`cmd` 照旧只入库绝不执行；删、挪之前电脑先看条目还在不在，不在只记一句不报错。
2. 🚨 **手机自己发的条目，在整板上出现过一次就记进 `board.seenKeys`**；电脑早就回执收到、又比整板早 10 分钟以上的也算进过——不然电脑上删了的会在手机上冒出来说「等电脑收」（2026-09-24 模拟器上实测踩到）。
3. 弹菜单、刷新前先把光标从空白框里拿出来，不然菜单一关键盘自己弹出来（同日实测）。
4. 空白框是多行框：见到换行就当回车发出去（模拟器实键回车只塞换行，不触发发送）。

## 拿什么验收

```
电脑：npm test（bookmark-board-sync 3 项、bookmark-inbox 加 2 项）
手机：flutter test（board_sync_test 8 项）；pwsh -File tool\build_apk.ps1 -Install 装到模拟器
```

2026-09-24 模拟器（新建的 BookmarkTest_API34）上连着真中转站、真看板全链路走过：手机拉到电脑整板（5 组、20 条、约 7K）；手机记一条 → 电脑收到 → 下一份整板里变成 01；长按挪到 Hermes → 电脑挪了；长按删掉 → 电脑删了；电脑上真敲命令领活、写报告 → 手机出「✅ 干完待审」→ 点「可以，删掉」→ 电脑删了。测试条目全清掉了。
