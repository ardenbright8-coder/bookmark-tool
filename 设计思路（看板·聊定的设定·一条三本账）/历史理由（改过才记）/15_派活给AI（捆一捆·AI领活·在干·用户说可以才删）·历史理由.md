# 设定 15 · 派活给AI —— 历史

## 2026-09-24 立（第一版）

**当时定成什么样**：点「启动 Agent」只把启动句放进剪贴板，提示「开一个新的 Claude 窗口，Ctrl+V 再回车」，窗口要用户自己开。自动开窗填字写了任务书，打算交给 ChatGPT 做。

## 2026-09-24 改（第二版）

**改了什么**：点「启动 Agent」顺手打开这个组对应的桌面快捷方式（Claude Code 一 / Codex / Pi 编程智能体 / Hermes），用户在新窗口里自己 Ctrl+V、回车。认不出的组、没有快捷方式，照旧只复制。交给 ChatGPT 的任务书作废，挪进 `书签工具\_old`。

**为什么改**：用户点了「启动 Agent」发现没开窗。摆了两种做法——只开窗，或者开窗再自动贴字——用户选了只开窗（「你先干第一个」）。原任务书要的是自动贴字，就是那种没被选上的做法。

## 2026-09-24 改（第三版）

**改了什么**：Claude、Pi 开出新命令窗口后，看板等它启动好替用户按一次 Ctrl+V，把启动句贴进去；回车照旧用户按。Codex、Hermes 不变。

**为什么改**：用户上机试第二版，新窗口开了却空着，以为没成功（「并没有说给新的 Claude Code 窗口发消息」），讲清两种做法后改选开窗再贴（「第二第二」）。

## 2026-09-24 改（第四版）

**改了什么**：Codex、Hermes 也替用户贴：认出这个程序跑到最前面、连续稳住 5 秒，按 Ctrl+N 新开对话，再按 Ctrl+V；回车照旧用户按。启动句提前在 Ctrl+N 时放进剪贴板。

**为什么改**：用户上机拉 Hermes、Codex，程序开了但启动句没进去（「Hermes 拉出来，但是他还是没贴进去」「Codex 也不行，也是贴不进去，那程序能打开」）。第三版故意没做桌面程序，用户要的是四家一样。

## 2026-09-24 补（第四版之后）

**改了什么**：多了第五组 Antigravity，「启动 Agent」开桌面「Antigravity 反重力CLI」，跟 Pi 一样是命令窗口；它开窗后要先登录，登录没完就贴会丢，所以这一家等 12 秒再贴（快捷方式表里单独写 `settleMs`）。

**为什么改**：用户要把谷歌的 Antigravity 加进看板（「再加一个 Agent 放到 Hermes 上面」）。实测按默认 4 秒贴，字贴在「Signing in…」那会儿，登录完输入框是空的。
