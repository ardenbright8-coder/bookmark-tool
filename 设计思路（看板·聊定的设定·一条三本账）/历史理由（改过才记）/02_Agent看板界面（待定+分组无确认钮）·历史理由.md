# 设定 02 · Agent 看板界面（待定+分组无确认钮） —— 历史

## 2026-09-10 立（第一版）

**当时定成什么样**：待定置顶、按 agent 分组、行尾无确认钮；右键或点左边小点弹「派给 →」各组，所有页都有。

## 2026-09-24 改（第二版）

**改了什么**：分组页、交接单专区的右键菜单不再列「派给 →」，改派靠拖到组头；待定页照旧有。

**为什么改**：他原话：「我会直接把这条消息拖动，而不是说发送给谁……那我就是可能重复了吧，功能性重复了嘛」。待定页跟分组不在同一页、拖不过去，所以待定页的留着。详见设定12。
