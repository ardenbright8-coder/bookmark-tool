# 设定02 · Agent 看板界面（待定+分组无确认钮） —— 现行理由

## 为什么有这条

**治的病**：记一条还要再点确认，麻烦；「让我想一想」的东西不该先派给某个 agent。

**他的原话**：

> 「发上去以后它会自动同步，我没必要再点一遍确认，麻烦死了」

**现在为什么选这个做法**：照他画的原型：待定置顶、按人分组、写下就同步。

**代价**：没有「点一下才算交出去」的闸门，写错了要自己改派或删。拍板时接受。
